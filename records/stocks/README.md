# A 股研究记录

每期使用一个 `YYYY-MM-DD` 目录。运行方式见 [周度筛选](../../README.md#运行周度筛选)。

- `screen.md` 记录数据截止时间、股票池、筛选规则和原始榜单。每个候选保留代码、因子数值、行业排名、数据来源和入围理由。
- `review.md` 记录候选复核结果。引用原始入围原因，写明财报与公告证据、估值假设、失效条件、结论和下次复查日。到期追加复盘。
- `snapshot.json` 保存该期成分、行业、行情、财务和分红输入，以及来源、采集时间和取数失败项。
- `evidence.json` 保存候选的巨潮公告标题、发布时间、原文链接或查询失败原因，并用输入快照的 SHA-256 关联当期榜单。

历史榜单是当期结果。规则变动从下一期生效，并记录变动内容。生成的 `review.md` 是复核工作底稿，完成原文核对后在同一份记录中追加判断和复盘。
