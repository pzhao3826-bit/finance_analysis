# 投资研究工作台

| 目录 | 用途 |
| --- | --- |
| `scripts/` | 黄金采集和 A 股周度研究脚本 |
| `data/gold/` | 黄金及相关指标的采集快照，运行时生成 |
| `data/stocks/cache/` | 按研究日期和标的缓存 A 股取数结果，运行时生成 |
| `records/gold/` | 黄金观察、持仓判断和后续复盘 |
| `records/stocks/` | A 股量化候选名单和个股复核记录 |

在项目目录运行 `python3 scripts/fetch_gold.py`，需要 Python 3.9+、`curl` 和网络。脚本下载近期黄金期货、广义美元指数、美国 10 年期实际利率和美元兑人民币，每次生成独立 JSON，保留来源、采集时间和观察日期。遇到数据源失败仍保存其他指标，并返回非零退出码。`--days 90` 可调整回看天数。观察日期可能因发布延迟而不同。

黄金使用 Yahoo Finance 的 `GC=F` 日线收盘价，单位为美元/盎司。它是期货行情，可能受换月影响，最新日线也可能仍在形成。美元指标使用美联储广义美元指数，与常见的 DXY 口径不同。宏观数据通过 FRED 获取。脚本由命令触发。

## 股市分析与选股流程

初版假设覆盖 A 股，持有观察期为 1–3 个月。首期以沪深 300 成分股作为候选范围，以沪深 300 同期回报作为基准。每周收盘后更新，遇到业绩、监管或重大经营公告时重新检查相关标的。市场、股票池、持有期和基准可在启动新一期研究前调整，发布后保留原口径供复盘。

### 运行周度筛选

在项目目录运行以下命令，需要 Python 3.9+、`curl` 和网络。BaoStock 通过 TCP 取数，巨潮资讯通过 HTTPS 提供公告链接。首跑需逐股获取数据，重跑会复用同日已缓存的请求。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-stocks.txt
python scripts/run_stock_research.py
```

每周最后一个交易日北京时间 18:00 后运行。省略日期时按交易日历使用最近交易日。当天为交易日且尚未到 18:00，命令会提示等待或显式指定更早的日期。`--as-of YYYY-MM-DD` 指定交易日，`--refresh` 重新请求同日缓存，`--no-announcements` 可单独跳过公告查询。盘后任务目前由命令触发。

每次发布会在 [A 股研究记录](records/stocks/README.md) 下生成完整一期。已有同日目录会保留，可在另一目录重跑，例如用当期输入离线复现：

```sh
period=records/stocks/2026-11-12
python scripts/run_stock_research.py --snapshot "$period/snapshot.json" \
  --evidence "$period/evidence.json" --output-dir /tmp/stock-replay
```

### 首版规则与数据口径

- 使用 BaoStock 按日查询的沪深 300 成分，要求恰好 300 个不同代码，且成分更新日不晚于研究日、间隔不超过 14 天。BaoStock 成分按周更新，做历史回测前还需要核对指数公司调样生效日。保存的快照能复现当次筛选，历史补采仍取决于供应商是否保存了财报的历次版本。
- 排除停牌、ST、当日成交额低于 1 亿元，以及当日行情或行业归属缺失的标的。按 BaoStock 返回的行业分类和行业分组，至少两只同行才排名。行情与行业覆盖各至少 90%，通过通用过滤的标的中，每个方向至少 70% 具备完整因子，且三套榜单均有结果，才会生成候选复核名单。数据不完整时保存诊断记录并返回退出码 `2`，无法构建有效快照时返回 `1`。
- **价值＋质量**使用正 PE TTM 的倒数与最近已披露报告期 ROE。**经营改善**要求归母净利润同比较上一报告期上升，再用同比和改善幅度评分。两者都将同行因子百分位等权平均。财报只有日期时，从披露日之后才纳入。**红利**使用近 365 天已除息的税前每股现金分红之和除以当日未复权收盘价，作为初筛指标，送转股等影响留待复核。
- 市场广度用个股近 20 个交易日的日涨跌幅连乘，已确认停牌日按零涨跌处理，历史行情缺口单列覆盖。行业相对强弱使用沪深 300 成分中可计算的同行等权涨幅减沪深 300 指数涨幅。
- 从三个方向依次挑至多三只不同标的，每个方向取尚未入选的首位，复核稿保留它在各榜单的排名。公告阶段只查这些候选，列出定期报告和近期公告的原文入口。巨潮返回的零点按仅有日期处理，研究当天只有日期的公告留到下一期核对。估值、催化剂和失效条件仍需阅读原文后填写。

## 每期怎么做

| 步骤 | 检查内容 | 产出 |
| --- | --- | --- |
| 1. 固定数据时点 | 记录行情截止时间、财报和公告的实际披露时间、当时的成分股名单。行情缺失或财报口径无法核实时，将相关标的留在观察名单。 | 数据日期、来源和缺失项 |
| 2. 判断市场环境 | 看沪深 300 的近 20 个交易日表现及其相对 60 日均线的位置、股票池近 20 日上涨比例、行业相对基准的强弱。指标分歧时记录分歧，避免用指数涨跌代替个股判断。 | 趋势、市场广度和强弱行业 |
| 3. 量化筛选 | 检查交易状态、成交额和数据完整性。使用决策时已披露的数据，按价值＋质量、经营改善、红利分别排序，保存因子值、排名和入围原因。 | 原始榜单和排除原因 |
| 4. 个股复核 | 从入围信号出发，读财报和公告验证变化是否真实、可持续，以及当前价格反映了什么预期。对银行等行业使用与商业模式匹配的指标。 | 每只股票的证据、估值假设、催化剂和反证 |
| 5. 发布名单 | 按证据质量、价格吸引力及下行情景排序，给出至多 3 只研究推荐。投资逻辑、估值依据、催化剂或失效条件写不清楚时，列入观察。允许本期无推荐。 | 推荐名单、观察名单及理由 |
| 6. 追踪与复盘 | 每周核对原假设。到达观察期限或触发失效条件时记录结果。用统一的可成交价格规则计算收益，计入分红和交易成本，并与同期同口径基准对照。 | 个股净收益、超额收益、最大回撤和判断复盘 |

财报和公告优先核对原文，行情、行业分类和历史成分记录实际使用的数据源。回测只使用决策时已披露的数据与当时的成分股，纳入后来调出或退市的历史标的。推荐发布后的第一个可成交时点作为模拟跟踪起点，遇停牌或涨跌停无法成交时记录延期或未成交。[巨潮资讯网](https://www.cninfo.com.cn/)

## 每期报告模板

- **研究日期与数据截止时间**｜____
- **市场环境**｜指数趋势 ____，上涨比例 ____，相对强弱行业 ____
- **本期结论**｜推荐 ____，观察 ____，暂缓原因 ____

每只推荐标的填写一张卡片。

| 字段 | 记录 |
| --- | --- |
| 股票与参考价格 | 代码、名称、价格、报价时间 |
| 核心判断 | 当前价格隐含的主要预期，以及哪项证据支持不同判断 |
| 估值与下行情景 | 估值口径、合理价格区间及关键假设，假设落空时的下行空间 |
| 催化剂 | 未来 1–3 个月可跟踪的事件、指标及预期时间 |
| 失效条件 | 会推翻判断的具体事实或指标变化 |
| 下次复查 | 日期、需要核对的指标和来源链接 |
| 到期复盘 | 实际可跟踪起止价格、含分红扣费收益、同期基准收益、最大回撤、原判断是否兑现 |

发布后保留原始推荐卡片。后续更新追加日期和新证据，便于区分原判断、后续修正与市场整体涨跌带来的收益。积累多期记录后，再检验哪些筛选条件与扣费后的超额收益有关。
